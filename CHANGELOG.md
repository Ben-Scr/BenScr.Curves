# Changelog

Created by Ben Schneider — https://github.com/Ben-Scr

## 1.0.0

- Seven finite/clamped easing functions and time-mapped cubic Bezier curves.
- Owning scalar keyframe tracks with copied keys, outgoing segment timing, exact key samples,
  endpoint clamping, explicit empty/moved-from states, and checked overshoot.
- C++20 header-only distribution through relocatable CMake exports and native NuGet integration.
- Deterministic numeric and ownership contracts, standalone-header tests, executable example,
  isolated CMake/NuGet consumers, and Windows/GCC/Clang verification workflows.
